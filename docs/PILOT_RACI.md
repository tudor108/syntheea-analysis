# Pilot RACI

All named people and Bayer-specific teams are **TO BE AGREED**. A role cannot approve its own
independent review evidence.

| Activity | Accountable | Responsible | Consulted | Informed |
|---|---|---|---|---|
| Approve pilot question and workflow | BAYER WORKFLOW OWNER: TO BE AGREED | Product/RWE lead: TO BE AGREED | Clinical, statistics, operations | Governance forum |
| Approve population, endpoint, time zero, censoring | CLINICAL/RWE OWNER: TO BE AGREED | RWE methodologist: TO BE AGREED | Biostatistician, source owner | Product owner |
| Confirm source fit and mappings | DATA OWNER: TO BE AGREED | Data engineer/steward: TO BE AGREED | RWE, privacy, security | Product owner |
| Approve privacy, legal, retention, and region | PRIVACY/LEGAL OWNER: TO BE AGREED | Privacy/legal teams: TO BE AGREED | Security, source owner | Governance forum |
| Approve security and access controls | SECURITY OWNER: TO BE AGREED | Platform/security engineer: TO BE AGREED | Privacy, data owner | Product owner |
| Approve statistical analysis and uncertainty | STATISTICAL OWNER: TO BE AGREED | Biostatistician: TO BE AGREED | RWE, data science | Governance forum |
| Evaluate model risk, harms, and subgroup support | MODEL-RISK OWNER: TO BE AGREED | Responsible-AI reviewer: TO BE AGREED | Clinical, statistics, operations | Governance forum |
| Execute reproducible analysis | ANALYTICS OWNER: TO BE AGREED | Analyst/data scientist: TO BE AGREED | Data engineering, RWE | Reviewers |
| Monitor stop criteria and incidents | WORKFLOW OWNER: TO BE AGREED | Operations/security: TO BE AGREED | Clinical, RWE, model risk | Governance forum |
| Make Stage-4/pilot decision | GOVERNANCE CHAIR: TO BE AGREED | Decision forum: TO BE AGREED | All approvers | Stakeholders |
